# Проект: Иерархия классов для корзины с продуктов

## Описание

Проект реализует систему работы с корзиной покупок, включающую иерархию классов для различных продуктов. Позволяет рассчитывать общую стоимость товаров с учётом скидок, а также выделять сумму вегетарианских продуктов.

## Структура проекта

### Пакеты и подпапки

- **`model`** — содержит классы, описывающие продукты и их характеристики:
  - ✅ **Абстрактный класс `Food`** — основа для всех продуктов;
  - ✅ **Классы‑наследники `Meat` и `Apple`** — реализации конкретных типов продуктов;
  - ✅ **Подпакет `constants`** — хранит константы для работы с цветами и скидками:
    - `Discount` — константы для значений скидок;
    - `Colour` — константы для цветов яблок (`red`, `green`).

- **`service`** — содержит логику работы с корзиной:
  - ✅ **Класс `ShoppingCart`** — реализует корзину с методами для расчёта сумм.

- **Класс `Main`** (вне пакетов) — точка входа в программу, содержит метод `main` для демонстрации функциональности.

## Иерархия классов

### 1. Абстрактный класс `Food` (пакет `model`)

**Поля** (доступны только из классов‑потомков):

- `amount` — количество продукта в кг (целое число);
- `price` — цена за единицу (вещественное число);
- `isVegetarian` — флаг вегетарианского продукта.

### 2. Интерфейс `Discountable` (пакет `model`)

**Метод:** `getDiscount()` — возвращает размер скидки (вещественное число).  
**По умолчанию:** возвращает `0`, если не переопределён.

### 3. Наследники класса `Food`

#### a) Класс `Meat`

- **Назначение:** представление мясных продуктов.
- **Конструктор:** принимает `amount` и `price`, устанавливает `isVegetarian = false`.

#### b) Класс `Apple`

- **Назначение:** представление яблок.
- **Дополнительные поля:** `colour` — цвет яблок (строка).
- **Конструктор:** принимает `amount`, `price` и `colour`, устанавливает `isVegetarian = true`.
- **Особенность:** для красных яблок (`colour = "red"`) метод `getDiscount()` возвращает `60` (скидка 60 %).

### 4. Класс `ShoppingCart` (пакет `service`)

**Поле:** массив элементов типа `Food`.  
**Конструктор:** принимает массив элементов `Food`.  
**Методы:**

- расчёт общей суммы товаров в корзине **без скидки**;
- расчёт общей суммы товаров в корзине **со скидкой**;
- расчёт суммы **вегетарианских** продуктов в корзине **без скидки**.

## Логика в методе `main` (класс `Main`)

1. **Инициализация данных:**
   - создаётся объект `Meat` (5 кг по 100 руб./кг);
   - создаются объекты `Apple`:
     - красные яблоки (10 кг по 50 руб./кг);
     - зелёные яблоки (8 кг по 60 руб./кг).

2. **Формирование корзины:**
   - создаётся массив продуктов из инициализированных объектов;
   - инициализируется корзина (`ShoppingCart`) с помощью массива продуктов.

3. **Расчёт и вывод результатов:**
   - общая сумма товаров **без скидки**;
   - общая сумма товаров **со скидкой**;
   - сумма **вегетарианских** продуктов **без скидки**.

## Принципы доступа к переменным

- все переменные класса **недоступны извне**, если не указано иное;
- доступ к переменным реализуется через **необходимые методы** — только те, которые нужны для функциональности.

## Цели проекта

- продемонстрировать работу с иерархией классов и наследованием;
- реализовать логику работы с корзиной покупок;
- показать использование интерфейсов для добавления функциональности (скидки);
- отработать работу с константами и пакетами.
